# SyncWrite

A real-time collaborative document editing platform.

## Features

- User authentication
- Create documents
- Share documents
- Real-time editing
- Document permissions
- Comments
- Version history

## Tech Stack

Frontend:
- Angular

Backend:
- ASP.NET Core

Database:
- PostgreSQL

Real-time:
- SignalR

- Docker
